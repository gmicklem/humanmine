## How these pages are made

`tools/source_manifest.py` (rdfc2im) collects the build manifest from the raw-data caches, the build logs and the mine; `tools/source_pages.py pages` turns it and the mapping files into these pages. `tools/full-build.sh --source-pages DIR` does both after the build's last phase. The field mappings of the stock loaders are in rdfc2im `rdfc2im/data/stock_mappings/`, read from the loaders' code; those of the RDF sources are rdfc2im's own mapping files. Counts over a raw file are made by streaming it (`tools/field_counts.py`) and cached under its sha256.
